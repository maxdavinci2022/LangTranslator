# LangTranslator

**Тап по кружку — страница переведена. Удержание — открылось меню.**

Юзерскрипт в одном файле: перевод страницы целиком, мгновенный перевод выделенного текста, замена текста прямо в полях ввода и озвучивание с настоящим голосовым движком.

[Установка](#установка) · [Управление](#управление) · [Озвучивание](#озвучивание) · [Настройки](docs/SETTINGS.md) · [English](README.md)

## Установка

1. Поставьте [Tampermonkey](https://www.tampermonkey.net/) или [Violentmonkey](https://violentmonkey.github.io/).
2. Откройте ссылку и подтвердите установку:
   `https://raw.githubusercontent.com/maxdavinci2022/langtranslator/main/langtranslator.user.js`
3. Обновите страницу — справа внизу появится круглая кнопка.

## Управление

| Жест | Результат |
| --- | --- |
| Тап / клик по кружку | Перевести всю страницу; повторный тап — вернуть оригинал |
| Удержание кружка (~0,5 с) | Открыть меню |
| Тап по значку `⋯` на кружке | Открыть меню |
| Правый клик по кружку | Открыть меню |
| Перетаскивание кружка | Переместить; положение запоминается |
| Выделение текста | Перевод сам появляется в окне результата |
| Тянуть за уголок окна результата | Изменить размер; двойной клик — сброс |
| `Alt` + `Z` | Перевести страницу / вернуть оригинал |
| `Alt` + `X` | Перевести выделенное; в поле ввода — заменить на месте |
| `Alt` + `C` | Открыть / закрыть меню |
| `Esc` | Закрыть диалог, окно результата, меню или остановить озвучивание |

Хоткеи расположены рядом и переназначаются в настройках.

## Озвучивание

В меню есть полноценная панель речи:

| Параметр | Диапазон |
| --- | --- |
| Голос / движок | все голоса системы либо «Авто · по языку текста» |
| Скорость | 0,5× – 2× |
| Тон | 0 – 2 |
| Громкость | 0 – 100 % |
| Проверить | произносит пример на текущем языке перевода |
| Остановить | останавливает чтение (кнопка есть и в шапке меню во время чтения) |
| Сброс | авто-голос, скорость 1×, тон 1, громкость 100 % |

Значения применяются сразу: сдвиньте ползунок во время чтения — оно начнётся заново с новым параметром. Длинный текст делится на куски, чтобы чтение не обрывалось. Если в браузере нет голосового движка, кнопки удаляются сами, а в меню появляется пояснение.

Все иконки — векторные SVG: никаких эмодзи-шрифтов и «квадратиков» вместо значков, одинаково на Windows, Linux, macOS и Android.

## Языки

Интерфейс сам берёт язык браузера, включая язык интерфейса Firefox через `Intl`. Доступны: **English, Русский, 中文, Deutsch, Français, Español**. Если языка нет в списке — английский.

Язык перевода по умолчанию — «Авто · язык браузера», исходный определяется автоматически. Всего 82 языка.

## Внешний вид

- **Прозрачность действует только на круглую кнопку.** Меню, диалоги, окно результата и уведомления всегда непрозрачные.
- **Тема меню: тёмная или светлая**, переключатель ☀/☾ в шапке меню и в настройках. Нейтральный графит и белый.
- Размер кнопки 34–64 px, перетаскивание, учёт безопасных зон, шторка снизу на телефоне.

## Настройки

Всё хранится под ключом `langtranslator.settings.v1` и переносится через JSON — см. [docs/SETTINGS.md](docs/SETTINGS.md).

Перенос между устройствами: **Скачать JSON → Загрузить файл → Применить**.

## Диагностика

Меню → Диагностика показывает определённые локали, выбранный голос, параметры речи и задержку либо причину отказа каждого сервиса перевода. Если везде `FAIL`, доступ закрыт сетью.
